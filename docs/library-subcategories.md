# Browsing tag subcategories

Open **Prompts & prefixes → Tags → Wiki categories and subcategories**. Every nonempty bundled Danbooru wiki group is a top-level category with its complete canonical vocabulary. Expand a parent or search for a finer branch, then check the branches you want. Checking a parent includes every tag in that wiki group.

Refined branches are intersected with their wiki parent. Where refinements leave tags uncovered, **Other … tags** contains the remainder. The union of a parent's children equals the parent; branches can overlap, so their counts are not additive. Wiki groups without useful refinements remain complete, selectable parents.

Multiple checked categories combine by union. Text/alias search, favorites, order, pagination and **Select all matching** operate on that same subset. Counts describe the pinned offline vocabulary, not a live Danbooru database or the user's Hydrus library. Parent links open the corresponding wiki page.

Source-card filters remain separate controls for deciding which incoming image tags contribute. Their existing IDs and saved choices remain compatible. Legacy vocabulary API category and refinement IDs also remain accepted, although curated source-transfer parents are no longer exposed as library roots.
